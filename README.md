# Cygnus AI Labs — AI Automation & Intelligence

> AI research and development that helps businesses bring structure to complex, unorganized processes. A UGS Product.

---

## Overview

**Cygnus AI Labs** website built with React 19, Tailwind CSS 4, and Framer Motion. Designed with a dark precision aesthetic, refined typography, restrained brand blue and teal accents, and purposeful, reduced-motion-aware animations.

---

## Sections

- **Navbar**: Glass blur header featuring the Cygnus AI Labs logo, navigation links, and primary CTA.
- **Hero**: Positioning headline, dynamic activity ticker, brand showcase card, and technology ecosystem marquee.
- **Capabilities (Features)**: Bento grid showcasing AI model development, process intelligence, intelligent automation, and responsible AI.
- **How It Works**: 3-stage process (Understand, Prototype & Validate, Deploy & Optimise) with count-up impact metrics.
- **Approach & Industry Domains (Insights)**: Core principles and domains served with grounded claims.
- **Engagements (Pricing)**: Scoped engagement tiers (Discovery, Build, Partner) with direct calls to action.
- **Footer**: Brand info, UGS product attribution, navigation links, and contact channels (`hello@cygnuslabs.ai`).

---

## Tech Stack

- **Framework:** React 19 + Vite 7
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion 12
- **Icons:** Lucide React
- **Marquee:** react-fast-marquee
- **Routing:** Wouter
- **Language:** TypeScript

---

## Getting Started

```bash
# Install dependencies
pnpm install

# Start development server
pnpm run dev

# Type check
pnpm run check

# Build for production
pnpm run build
```
